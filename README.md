# dark-founder-portfolio

A minimal dark one-page portfolio starter for solo builders, founders, and product engineers, maintained by Vaguul under the Zemiax personal software studio.

## Includes

- responsive single-page layout
- dark premium palette
- hero, direction, focus, and stack sections
- no build step required

## Usage

Use this repository as a GitHub template, or clone it directly.

Open `index.html` and replace the placeholder text, links, and colors with your own brand.
