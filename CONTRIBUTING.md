# Contributing

Thanks for considering a contribution.

## Good first changes

- Improve accessibility, responsive layout, or documentation.
- Keep the starter simple and easy to copy.
- Avoid build steps unless they remove real maintenance cost.

## Local validation

Open `index.html` in a browser and check desktop, mobile width, keyboard navigation, and link behavior.

## Pull requests

- Keep placeholder content generic.
- Do not add tracking scripts, paid assets, or private product claims.
- Keep the template usable without a build step.
